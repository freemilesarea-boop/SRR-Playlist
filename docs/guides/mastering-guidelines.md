# 듣다 권장 마스터링 / 음원 등록 기준 (초안)

> 목적: 일관되고 예측 가능한 음원 등록 기준 안내. **방송국 수준 마스터링을 강요하지 않으며**, 매장 DSP 운영에 맞춘 실용 기준입니다.

## 핵심 요약
| 항목 | 권장 (이상적) | 허용 (등록 가능) | 등록 차단 (Hard Reject) |
|---|---|---|---|
| Integrated LUFS | **−13 ~ −10 LUFS** | −16 ~ −8 LUFS | < −16 또는 > −8 (극단값) |
| True Peak | **≤ −1.0 dBTP** | ≤ 0.0 dBTP | **> 0.0 dBTP (실측 클리핑)** |
| Clipping | 0 dBFS 미도달 | 짧은 트랜지언트 허용 | 지속/심각 클리핑 |
| 파일 | WAV 44.1kHz/24bit, stereo | MP3 320k 등 | 손상/디코드 불가/길이 0 |

## 1. 볼륨 (Integrated LUFS)
- 듣다는 매장 내 일관된 청취감을 위해 대략 **−13 ~ −10 LUFS** 를 권장합니다(스트리밍 평균대와 매장 체감의 절충).
- **−16 ~ −8 LUFS 면 등록 가능**합니다. 라우드한 K-POP/EDM 마스터(−9 ~ −8)도 허용됩니다.
- 너무 조용한(< −16) 또는 과도하게 라우드한(> −8) 마스터만 차단됩니다.

## 2. True Peak (가장 흔한 반려 원인)
- 권장: 마스터 True Peak 를 **−1.0 dBTP 이하**로 두세요(인터샘플 피크 여유).
- 듣다는 등록 시 음원을 **표준 MP3(192k)로 변환**합니다. 손실 변환 과정에서 **인터샘플 오버슈트(최대 +0.5~+1 dB)** 가 생길 수 있어, 마스터를 −1.0 dBTP 이하로 두면 변환 후에도 안전합니다.
- **등록 차단은 실측 True Peak > 0.0 dBTP(실제 클리핑)인 경우에만** 적용됩니다. −1.0 ~ 0.0 dBTP 구간은 경고로만 처리하며 등록 가능합니다.

## 3. Clipping
- 0 dBFS 에 지속적으로 도달하는 마스터(과한 리미팅)는 음질 저하와 디지털 클리핑을 유발합니다.
- 짧은 순간 트랜지언트는 허용되며, **지속적/심각한 클리핑만** 차단 대상입니다.

## 4. 파일 스펙
- 권장: **WAV 44.1kHz / 24bit / Stereo** (무손실). FLAC 도 가능.
- MP3 업로드 시 320kbps 권장.
- 손상 파일, 디코드 불가, 길이 0/비정상 파일은 등록 불가.

## 5. 과도한 마스터링 주의
- "최대한 크게"만을 목표로 한 과압축(브릭월) 마스터는 매장 스피커에서 오히려 답답하게 들릴 수 있습니다.
- 적정 다이내믹을 유지한 −12 LUFS 내외 마스터가 매장 환경에서 가장 안정적입니다.

## 6. 반려되었을 때
- 측정값(LUFS / True Peak)이 안내 메시지에 표시됩니다.
- True Peak 만 살짝 초과한 경우: 마스터 리미터 ceiling 을 −1.0 dBTP 로 낮춰 재출력 후 재업로드하면 해결됩니다.
- 볼륨만 문제인 경우: 위 허용 범위(−16 ~ −8 LUFS)로 조정.
- 경미한 사례는 관리자 검수에서 승인될 수 있습니다(아래 운영 정책 참조).
